
This document summarizes operational confirmations received from Nikon support regarding Display 5 (“Info”) behavior on the Nikon Z f.

## [CASE 01](Nikon_Support_Confirmation_Notes.md#case01). Power-Cycle Persistence of Display 5
> Confirmation that the Display 5 (“Info”) display persists across power cycles.

## [CASE 02](Nikon_Support_Confirmation_Notes.md#case02). MENU Half-Press Returns to Display 5
> Confirmation of the phenomenon where, after displaying the MENU, a half-press returns to the Display 5 (“Info”) display instead of Live View.

## [CASE 03](Nikon_Support_Confirmation_Notes.md#case03). EVF Live View Appears Temporarily, but LCD Returns to Info
> Confirmation of the phenomenon where, after displaying the MENU, Live View is displayed in the EVF by a half-press, but the display returns to Display 5 (“Info”) when removing the eye from the EVF.

## [CASE 04](Nikon_Support_Confirmation_Notes.md#case04). LCD Opening Changes Info Recovery: DISP Route
> Confirmation of the phenomenon where the Info screen displayed by a single press of the DISP button initially does not possess fixation characteristics, but changes into one that persists after passing through the action of opening the LCD.

## [CASE 05](Nikon_Support_Confirmation_Notes.md#case05). LCD Opening Changes Info Recovery: [i] / Fn Routes
> Confirmation of the phenomenon where the Info screen displayed by operating the [i] button or Fn button also changes into one that persists after passing through the action of opening the LCD, similar to CASE 04.

## [CASE 06](Nikon_Support_Confirmation_Notes.md#case06). Display 5 Disabled: Info No Longer Fixates, but Display Index Resets
> Confirmation of the phenomenon where the fixation phenomenon can be avoided by disabling the Display 5 display, but the Display number is reset to Display 1 after passing through the Info screen display.

## [CASE 07](Nikon_Support_Confirmation_Notes.md#case07). DISP Disabled: Practical Lock / Recovery Failure
> Confirmation of the phenomenon where disabling the DISP button function makes it difficult to clear the persisted Info screen.

## [CASE 08](Nikon_Support_Confirmation_Notes.md#case08). Info Display During Burst Shooting
> Confirmation of the phenomenon where Display 5 (“Info”) continues to persist during continuous shooting under default settings.







これらの現象がなぜ発生するのか、ソフトウェアのステート管理や「道具としてのカメラ」の思想から深く掘り下げた検証・考察は、以下の本編ドキュメントを参照されたい。





This document summarizes operational confirmations received from Nikon support regarding Display 5 (“Info”) behavior on the Nikon Z f.

## CASE 01. Power-Cycle Persistence of Display 5
> Display 5 (“Info”)の表示が，電源再投入を跨いで維持されることの確認

## CASE 02. MENU Half-Press Returns to Display 5
> MENUを表示した後，シャッターボタン半押しでライブビューでなくDisplay 5 (“Info”)の表示に戻る現象の確認

## CASE 03. EVF Live View Appears Temporarily, but LCD Returns to Info
> MENUを表示した後，EVFではシャッターボタン半押しでライブビューが得られるが，離眼するとDisplay 5 (“Info”)の表示に戻る現象の確認

## CASE 04. LCD Opening Changes Info Recovery: DISP Route
> DISPボタン１回の押下で表示されるInfo画面は当初は固着特性を持たないが，液晶展開を経由することで固着するものに変化する現象の確認

## CASE 05. LCD Opening Changes Info Recovery: [i] / Fn Routes
> [i]ボタンやFnボタン操作によって表示されるInfo画面もCASE 04同様に，液晶展開を経由することで固着するものに変化する現象の確認

## CASE 06. Display 5 Disabled: Info No Longer Fixates, but Display Index Resets
> Display 5 の表示を無効化することで固着現象は回避できるが，Info画面表示を経由することで Display番号がDisplay 1 にリセットされてしまう現象の確認

## CASE 07. DISP Disabled: Practical Lock / Recovery Failure
> DISPボタン機能を無効化することで，固着したInfo画面の消去が困難になる現象の確認

## CASE 08. Info Display During Burst Shooting
> デフォルト設定のもとで，連写中にDisplay 5 (“Info”)が表示され続ける現象の確認．
